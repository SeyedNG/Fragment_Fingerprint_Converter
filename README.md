## ⚡ امکانات کلیدی

* 🔒 **صد در صد کلاینت-ساید:** تمام تحلیل و تبدیل کانفیگ‌ها داخل مرورگر انجام می‌شه و هیچ داده‌ای به سروری ارسال نمی‌شه.
* 🧩 **موتور TLS Fragment:** تکه‌تکه کردن TLS Hello برای عبور از DPI و فیلترینگ بر پایه SNI.
* 🚀 **رفع کندی آپلود:** تنظیم پارامترهای لایه‌ی انتقال برای رفع محدودیت سرعت آپلود روی ورکرهای کلودفلر.
* 🔄 **دریافت خودکار ساب لینک:** دریافت و دیکد لینک‌های سابسکرایپ base64 داخل مرورگر، با چند مسیر جایگزین برای زمانی که یکی از پروکسی‌ها کند یا مسدود باشه.
* 📁 **چند روش ورودی:** وارد کردن مستقیم لینک، آپلود فایل `.txt` یا دریافت از لینک ساب — همه قابل ترکیب با هم قبل از تبدیل.
* 🇮🇷 **قوانین مسیریابی اختیاری:** فعال/غیرفعال‌سازی مسدودسازی تبلیغات و بایپس سایت‌های ایرانی (`.ir`).
* 🌐 **تغییر آی‌پی کانفیگ:** امکان جایگزینی آدرس سرور هر کانفیگ با یکی از آی‌پی‌های دلخواه خودتون.
* 📤 **دو فرمت خروجی:**
  * **عادی** — لینک‌های ساده‌ی `vless://` / `trojan://` برای کلاینت‌های [PattN](https://github.com/patterniha/PattN/releases/latest) / [PattNG](https://github.com/patterniha/PattNG/releases/latest).
  * **کاستوم (JSON)** — کانفیگ کامل Xray، قابل دانلود به‌صورت یک فایل `ff.txt` یا فایل‌های JSON جداگانه داخل یک ZIP (برای کلاینت‌هایی مثل v2rayN که هر کانفیگ رو باید در فایل مجزا وارد کنن).
* 🏷️ **حفظ ریمارک اصلی:** ریمارک/نام هر کانفیگ همون چیزیه که در ورودی بوده و در تبدیل تغییر نمی‌کنه.

## 🛠️ راهنمای استفاده

1. فایل `index.html` رو در مرورگر باز کنید یا از [نسخه آنلاین](https://seyedng.github.io/Fragment_Fingerprint_Converter/) استفاده کنید.
2. لینک‌های `vless://` / `trojan://` رو وارد کنید، از لینک ساب دریافت کنید یا فایل `.txt` آپلود کنید.
3. فرمت خروجی (عادی یا کاستوم JSON) رو انتخاب کنید و تنظیمات مسیریابی / آی‌پی رو مشخص کنید.
4. روی **تبدیل کانفیگ‌ها** بزنید و خروجی رو کپی یا دانلود کنید (`ff.txt`، یا گزینه‌ی ZIP جداگانه برای خروجی کاستوم).

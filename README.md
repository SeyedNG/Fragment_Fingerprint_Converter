## ⚡ امکانات کلیدی

* 🔒 **صد در صد پردازش محلی (Client-Side):** کلیه فرآیندهای تحلیل و ساخت فایل خروجی درون مرورگر کاربر انجام شده و هیچ داده‌ای به سرور ثالث ارسال نمی‌شود.
* 🧩 **سیستم TLS Fragment پیشرفته:** اعمال جفت‌سازی تکه‌های TLS Hello و تنظیمات فریم‌بندی جهت دور زدن فیلترینگ و SNI Inspection.
* 🚀 **رفع کندی آپلود:** بهینه‌سازی پارامترهای ارتباطی بر پایه استراتژی‌های جدید هسته Xray.
* 🔄 **دریافت خودکار از لینک سابسکرایپ:** قابلیت فراخوانی لینک‌های ساب با بهره‌گیری از سیستم فال‌بک پروکسی‌های CORS جهت دور زدن محدودیت‌های مرورگر.
* 🇮🇷 **مسیریابی هوشمند (Routing):** امکان جداسازی خودکار ترافیک سایت‌های ایرانی (`.ir`) و مسدودسازی تبلیغات به صورت اختیاری.
* 📥 **خروجی استاندارد `ff.txt`:** تولید فایل خروجی سازگار با کلاینت‌های مدرن نظیر v2rayNG و NekoBox.

## 🛠️ راهنمای استفاده

1. فایل `index.html` را در مرورگر باز کنید یا از نسخه آنلاین استفاده نمایید.
2. کانفیگ‌های `vless://` یا `trojan://` خود را وارد کنید (یا لینک سابسکرایپ/فایل متنی را بارگذاری کنید).
3. تنظیمات مسیریابی (حذف تبلیغات / میان‌بر سایت‌های ایرانی) را بر اساس نیاز خود مشخص کنید.
4. روی دکمه **تبدیل کانفیگ‌ها** کلیک کرده و خروجی را کپی یا به صورت فایل `ff.txt` دانلود کنید.
